## RC 与 Alpha 开发基线评估

当前基线已更新为 0.2.1-rc.2，见[当前同步记录](上游同步-0.2.1-rc.2.md)；[RC.1 记录](上游同步-0.2.1-rc.1.md)保留升级历史。下文保留为 2026-10-16 的选择依据。

2026-10-16 评估建议：W1 当前继续固定 `dsh-v0.2.1-alpha.4` 做开发基线，保留 `dsh-v0.2.0-rc.2` 作为现用版本和兼容性对照。持续跟踪所有上游新发布，包含每个 Alpha；固定基线只表示检查器不自行切换代码，用户发起跟进并完成合并验证后更新基线。本轮没有切换分支、启动应用或更改现用 DSH。

理由与边界：

- 两个标签属于不同版本系列：0.2.0 的 RC 代表其候选阶段，不能直接据名称推断它比后续 0.2.1 Alpha 的每项实现都稳定。GitHub 两者均标为 prerelease。
- 本地完整历史比较得到 RC.2 到 Alpha.4 新增可达提交数为 1,876，包含代码、文档、发布和合并，不是独立功能数。差异规模意味着旧基线后续吸收改动的成本需要考虑，也意味着新基线有更多待回归的行为。
- Alpha.2 新增 working_directory 服务与工具；本地 RC 标签没有 packages/session/working-directory，Alpha 标签有。它将会话执行目录独立出来，直接有利于 W1 的多目录项目设计，但不会自动提供主要目录模型。
- Alpha.3 发布说明包含插件更新后旧代码仍生效、重启后会话无法继续等修复；与现有使用痛点有关，不能把发布说明当作 W1 已完成对应回归。
- Alpha.4 增加自定义模型推理等级 UI，并调整第三方插件兼容性判断，优先使用 engines.dsh；W1 后续接入旧插件需要复验，不能默认兼容。
- 当前 Alpha.4 在本机通过原版完整构建、lint、实际 Electron 启动和设置页检查；尚未覆盖真实模型请求、长会话恢复、现有插件和安装器。
- RC.2 使用 pnpm 11.7.0、Electron 清单范围 ^44.0.0；Alpha.4 使用 pnpm 11.28.5、Electron 清单范围 ^44.7.0。环境与插件支持也需跟随具体基线验证。

若目标改为尽快替换日常主力，优先考虑已充分验证的 RC/正式版，或先补齐 Alpha 的实际工作回归。当前是独立隔离开发阶段，Alpha.4 能减少重复移植，已有原版构建证据；此结论不是对 Alpha 普遍更稳定的判断。

进入日常使用前至少补齐：真实模型与工具调用、长会话/重启恢复、用量和通知插件、目录权限、浏览器会话与安装更新。遇到不可接受的基础回归时再评估回退源码基线；不能让旧程序直接读取新版本测试数据来假设可回退。

## Codex 主要目录：已确认行为与证据范围

2026-10-16 用户新截图显示两个源文件夹：DeepSeek Harness 标记“主要”，W1 Harness 显示“设为主要”，并可看到其真实路径。已确认当前客户端提供主要目录角色，替代先前“截图仅显示一个目录、入口待观察”的结论。本轮 list_projects 返回该项目的主路径仍是 E:\ProjectDev\DeepSeek Harness，与截图一致；该接口不提供完整目录列表，不能据它推断其他目录不存在。

官方项目文档明确描述如下行为；本轮重新读取了对应原文：

| 事项 | 主要目录 | 其他源文件夹 |
|---|---|---|
| 新聊天默认执行位置 | 默认 cwd | 可作为任务显式操作目标，不是默认 cwd |
| 文件使用 | 在授权内搜索、读取、编辑 | 同样可在授权内搜索、读取、编辑，不是只读附件 |
| 默认 Git | 默认仓库；PR 与 worktree 操作目标 | 保持各自仓库身份；不会合并成主仓库 |
| 修改查看 | 可查看主仓库变更 | Review 可显示同一项目关联的其他仓库变更 |
| 规则与配置发现 | 自动发现项目 AGENTS.md、skills、config.toml 的默认入口 | 不自动按主目录方式发现这些项目文件；不表示文件内适用指令可以忽略 |
| worktree 聊天 | 在主要仓库建立 worktree | 其他目录仍保持关联 |
| 权限 | 受 sandbox 控制 | 同样受 sandbox 控制；主要标记本身不是提权 |

这是默认操作角色，不是模型注意力分配权重。官方文档没有承诺把主要目录内容全部加载进上下文，也没有说次要目录的内容不重要。

已确认层次为截图、当前项目元数据和官方行为文档；本轮未反编译 Codex、未替用户切换主要目录，也未通过切换实验确认旧聊天或运行中终端如何变化。文档明确保证的是“新聊天”从主要目录开始，不能外推为旧会话自动切换。W1 对切换、移除、离线和权限的具体要求见[项目规划](项目规划.md)。

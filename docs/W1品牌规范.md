# W1 品牌规范

本参考页规定 W1 系列公共 Fold 图标及其在 W1 Harness 中的导出方式。品牌含义为“一分白 / White One”；图形由折带式 W、斜向分隔和右侧暗示数字 1 的竖折组成。Fold 不归 Harness 独占，各产品专属图标尚待设计与确认。

## 资源分类与取用

系列共用副本位于 `E:\ProjectDev\W1-Brand`，入口为该目录的 README.md，当前素材包位于 assets/fold/1.1.0/。2026-11-04 从本仓库交付包复制 61 个文件并逐项核对 SHA256，原件保留；历史概念图另放 references/。共享资产与产品使用状态分开维护，复制不改变各产品现有图标或构建路径。

日常取图使用共享目录 `E:\ProjectDev\W1-Brand\assets\fold\1.1.0`，按头像、透明标志、应用图标、预览、源文件分类；源码与导出入口见[素材说明](../assets/w1/README.md)。头像使用铺满背景的 RGB PNG；透明标志用于已有背景；圆角底板和 ICO 用于应用。原交付包保留在日用仓库 releases/w1-brand/<素材版本>/，旧版本不覆盖。

## 标准文件

唯一几何源文件为 [mark.svg](../assets/w1/mark.svg)，版本为 v1.1（视觉居中候选，日用应用状态见工作记录）。轮廓以原始概念板右下角 D 为依据，保留其左右折带衔接、斜率与转角，不另行圆润化。图形使用 512 × 512 坐标、五个闭合填充路径，不依赖字体、描边、外部图片或滤镜。相对 v1.0 仅在 512 坐标内左移 12、上移 5，统一使用 `translate(-692 -585)`；五条路径及其相对位置不变。带底图标沿用 80% 缩放，实际平移为左 9.6、上 4；视觉补偿不以面积重心完全归零为目标。SVG 的 `currentColor` 允许内联时继承前景色；独立图片使用固定颜色导出版本。

## 使用规则

- 新会话主标题使用「所想，皆有回响」，英文为「Every thought finds an echo」。主标题保留 Fold 图标，去除旁边的“预览版”标记，不另行迁移该标记；输入框提示沿用原文。
- 等比缩放，保持五段图形、切缝和方向；不要拉伸、旋转、描边、添加阴影或改变单段比例。
- 保留标准 SVG 的画布留白。自由排版时，图形外轮廓到其他内容的距离至少为图形宽度的 1/8。
- Windows 窗口、任务栏、托盘及已有 W1 快捷方式统一使用白底深标 `w1-app-light.ico`，不随 Windows 系统模式或应用模式切换。深底白标 `w1-app-dark.ico` 随资源发布，但不用于这些位置。Chrome 工具栏与扩展管理卡片保持深底白标，避免透明白标不可见。应用底板为 512 坐标中的 `(16,16,480,480)`，圆角半径为 104，标志居中缩至 80%。
- 界面优先使用 32 像素及以上；16–24 像素用于空间受限位置，细切缝会因抗锯齿弱化。选择匹配目标尺寸的 PNG 或使用 SVG，避免放大低分辨率文件。
- 产品名称写作 `W1 Harness`；图标内部不嵌入产品文字。左上角由 Fold 图标与 HARNESS 字标组成，不重复显示文字 W1，也不使用分隔斜线。HARNESS 使用已有本地 Montserrat 500、15px 字号和 0.1em 字距，继承明暗主题颜色；无障碍名称仍为 W1 Harness。

## 重建导出文件

在已安装锁定依赖的项目根目录运行：

```powershell
node scripts/w1/export-brand.mjs
```

[导出脚本](../scripts/w1/export-brand.mjs)使用桌面包现有的 Sharp 依赖读取唯一几何源，重建四个 SVG、四十二个 PNG、四个八帧 ICO 和预览图。修改图形后应重建并检查明暗背景与小尺寸，不直接修改导出文件。脚本同时同步桌面 ICO、Chrome 扩展和手机端品牌资源；已发布版本目录保持不变。侧栏、首屏及运行状态内联 SVG 的位移须与主文件一致。

## 接入与验收

图标路径由 `w1SystemIconPath` 恒定为白底深标，每次启动写入窗口、托盘与已有快捷方式，新建窗口沿用同一路径；不读取 `nativeTheme`，也不监听主题更新或 `WM_SETTINGCHANGE`。快捷方式修改保留目标、应用身份及其他字段，并在用户数据目录 shortcut-icon-backups 中保存首次修改前副本。2026-10-23 用户要求图标形态固定，本规则取代 2026-10-20 的按应用模式切换方案。

W1 首版已将既有资产接入侧栏、会话首屏、桌面窗口、托盘与打包资源。浏览器品牌组件的路径来自标准 SVG 导出，保持轮廓不变；更新几何源时需要同时核对该组件与导出资源。Windows 实际显示、安装器和安装包的验收统一见[首版构建与验收](首版构建与验收.md)。

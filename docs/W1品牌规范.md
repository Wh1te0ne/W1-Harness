# W1 品牌规范

W1 Harness 使用 W1 Brand 本地 `2.0.0-preview.4` 快照的字高对齐 Logo，App 图标仍为 fold-flat 暂定稿。来源为 `E:/ProjectDev/W1-Brand` 的 `codex/logo-cap-alignment-20261105` 未提交工作区；该快照尚无 GitHub 标签或对应提交，实际消费文件与清单摘要固定保存。品牌版本与 W1H 产品版本分别管理。

## 来源与取用

[source.json](../assets/w1/brand/source.json) 记录本地来源、基线提交、清单摘要及逐文件 SHA256。[品牌副本](../assets/w1/brand/2.0.0-preview.4/) 包含本产品实际消费的资源、对齐规范与授权文件；运行导出入口见[素材说明](../assets/w1/README.md)。品牌图形遵守[独立授权](../assets/w1/LICENSE)，不随代码许可证重新授权。

| 使用位置 | 正式资源及规则 |
|---|---|
| 展开侧栏、手机页面标题 | 横向母标与 HARNESS 字标按 W 主体字高对齐；以 48px 高度显示为 184.4 × 48，名称加长时增加宽度 |
| 折叠侧栏、会话首屏、运行状态 | 保留原 Fold 母标的紧凑展示；不修改母标路径 |
| Windows 窗口、托盘、任务栏、启动器 | 全部使用透明前景 ICO，无方形底板；按 Windows 系统明暗选择深色或浅色图形 |
| Web/PWA | 明暗主题产品图标；安装图标以浅色方图为源，maskable 图将完整前景及镂空等比缩至 82%，背景保持铺满 |
| Chrome 扩展、Android 源资源 | 深底浅标的产品图标；安装状态以各平台交付记录为准 |

横向 Logo 的浅色主题使用前景 `#252A33`、背景 `#FFFFFF`；深色主题使用前景 `#F5F6F8`、背景 `#17191F`。App 图标浅色背景为 `#F4F5F6`，其余配色遵循固定图标源，不由 Logo token 覆盖。横向 Logo 使用两份正式 SVG，跟随应用实际主题；手机页面跟随系统主题。不要通过 `invert()` 变色。App 源图为完整 1024 × 1024 方图，不预制圆角；平台需要裁切时由平台处理。

## 导出与更新

```powershell
node scripts/w1/export-brand.mjs
```

[导出脚本](../scripts/w1/export-brand.mjs) 核对固定资源的 SHA256，再生成 `assets/w1/exports/` 的固定消费路径、桌面 ICO、客户端资源、Web 安装图标及手机和 Chrome 源资源。正式 1024 PNG 原样复制；平台尺寸由正式图派生。Windows App ICO 从正式透明前景 SVG 生成，四角及 W1 镂空保持透明；完整 PNG/SVG 方图仍供 Web 和其他平台使用。每个 ICO 包含 16、20、24、32、48、64、128、256 像素八帧；透明母标另有 8192 像素 PNG。不得直接修改生成文件或改变产品轮廓与镂空母标的相对位置。分层 SVG 使用原始 512 坐标，导出保留其整体两倍缩放；PWA 只缩放 foreground 图层，校验缺少原始缩放或背景的文件时明确失败。

常规品牌更新固定已批准的标签或提交；用户明确要求使用本地稿时，记录工作区与基线提交并校验复制期间的清单稳定性，不编造发布状态。更新固定资源与校验值后运行导出；W1 正在运行时加 `--skip-desktop-icons`，待正常退出后再复制桌面 ICO。已发布版本目录、原始概念图与恢复副本保留。`E:\ProjectDev\W1-Brand\assets\fold\1.1.0` 和本仓库 `releases/w1-brand/1.1.0` 是旧母标素材包，版本名称不代表新的品牌仓库版本；当前产品应从本页固定来源取用。

## 本机接入

`prepareW1SystemIcon` 将选定的透明 ICO 复制到用户数据目录 `system-icons/w1-app-<内容摘要>.ico`，窗口、任务栏、托盘与已有 W1 快捷方式共用这一版本路径。只跟随 Windows 系统主题，不受应用自己的深浅色选择影响；退出时解除主题监听，旧缓存文件保留以免既有快捷方式失效。安装器同样使用内容命名的图标文件并通知 Explorer 刷新，避免替换同名文件后继续显示旧缓存。

客户端与桌面主包先暂存，正常退出后应用队列并安装启动器。备份、实际加载路径和用户目视确认分别留痕；仅核对 ICO 或 EXE 文件不代表任务栏缓存已经刷新。

新会话标题仍为「所想，皆有回响」/「Every thought finds an echo」。本次品牌更新不改会话、模型、计价或插件配置。自动检查、实际运行资源与用户目视验收分别记录在[工作记录](工作记录.md)；手机 APK、扩展商店和安装包的发布不能由源码资源同步推定。

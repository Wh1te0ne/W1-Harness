# W1 品牌规范

本参考页规定 W1 Harness 的 Fold 图标及导出方式。品牌含义为“一分白 / White One”；图形由折带式 W、斜向分隔和右侧暗示数字 1 的竖折组成。

## 标准文件

唯一几何源文件为 [mark.svg](../assets/w1/mark.svg)，版本为 v1.0。轮廓以原始概念板右下角 D 为依据，保留其左右折带衔接、斜率与转角，不另行圆润化。图形使用 512 × 512 坐标、五个闭合填充路径，不依赖字体、描边、外部图片或滤镜。SVG 的 `currentColor` 允许内联时继承前景色；独立图片使用固定颜色导出版本。

| 文件 | 用途 |
|---|---|
| [黑标 SVG](../assets/w1/exports/mark-dark.svg) | 浅色背景，颜色 `#17191F`，透明画布 |
| [白标 SVG](../assets/w1/exports/mark-light.svg) | 深色背景，颜色 `#FFFFFF`，透明画布 |
| [应用图标 SVG](../assets/w1/exports/app-icon.svg) | 深色圆角底、白色标志，四角透明 |
| [浅色应用图标 SVG](../assets/w1/exports/app-icon-light.svg) | 白色圆角底、深色标志，四角透明 |
| [Windows ICO](../assets/w1/exports/app-icon.ico) | 包含 16、20、24、32、48、64、128、256 像素的八帧图标 |
| [尺寸与配色预览](../assets/w1/preview.png) | 黑白标志、应用图标及实际像素尺寸对照 |
| [原始概念板](../assets/w1/reference-concepts.png) | 用户选择右下角 D 的视觉参考；不作为发布图标 |

`assets/w1/exports/` 同时提供四种版本的 PNG，尺寸为 16、20、24、32、48、64、128、256、512、1024 像素，命名为 `<版本>-<尺寸>.png`。这些文件随品牌资产保留，可由脚本重建。

## 使用规则

- 新会话主标题使用「所想，皆有回响」，英文为「Every thought finds an echo」。主标题保留 Fold 图标，去除旁边的“预览版”标记，不另行迁移该标记；输入框提示沿用原文。
- 等比缩放，保持五段图形、切缝和方向；不要拉伸、旋转、描边、添加阴影或改变单段比例。
- 保留标准 SVG 的画布留白。自由排版时，图形外轮廓到其他内容的距离至少为图形宽度的 1/8。
- Windows 窗口、任务栏、托盘及已有 W1 快捷方式统一跟随应用模式：浅色为白底深标，深色为深底白标。底板与标志一起切换，不再把托盘与任务栏分开，也不再按 Windows 系统模式选透明单色标。Chrome 工具栏与扩展管理卡片保持深底白标，避免透明白标不可见。应用底板为 512 坐标中的 `(16,16,480,480)`，圆角半径为 104，标志居中缩至 80%。
- 界面优先使用 32 像素及以上；16–24 像素用于空间受限位置，细切缝会因抗锯齿弱化。选择匹配目标尺寸的 PNG 或使用 SVG，避免放大低分辨率文件。
- 产品名称写作 `W1 Harness`；图标内部不嵌入产品文字。左上角由 Fold 图标与 HARNESS 字标组成，不重复显示文字 W1，也不使用分隔斜线。HARNESS 使用已有本地 Montserrat 500、15px 字号和 0.1em 字距，继承明暗主题颜色；无障碍名称仍为 W1 Harness。

## 重建导出文件

在已安装锁定依赖的项目根目录运行：

```powershell
node scripts/w1/export-brand.mjs
```

[导出脚本](../scripts/w1/export-brand.mjs)使用桌面包现有的 Sharp 依赖读取唯一几何源，重建四个 SVG、四十个 PNG、四个八帧 ICO 和预览图。修改图形后应重建并检查明暗背景与小尺寸，不直接修改导出文件。

## 接入与验收

应用模式使用 nativeTheme.shouldUseDarkColors，运行时响应 nativeTheme 更新及 WM_SETTINGCHANGE，两处同时切换。退出后不驻留监听，下次启动同步。快捷方式修改保留目标、应用身份及其他字段，并在用户数据目录 shortcut-icon-backups 中保存首次修改前副本。2026-10-20 用户明确要求统一应用模式，本规则取代之前的系统模式透明图标方案。

W1 首版已将既有资产接入侧栏、会话首屏、桌面窗口、托盘与打包资源。浏览器品牌组件的路径来自标准 SVG 导出，保持轮廓不变；更新几何源时需要同时核对该组件与导出资源。Windows 实际显示、安装器和安装包的验收统一见[首版构建与验收](首版构建与验收.md)。

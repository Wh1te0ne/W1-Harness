# W1 品牌规范

W1 Harness 使用 W1 Brand `2.0.0-preview.14` 的字高对齐 Logo 和折面平面 App 图标。石墨灰配色已获确认，包含菱形、箭头与 W1 镂空的图标整体仍为暂定稿。品牌版本与 W1H 产品版本分别管理。

## 来源与取用

[source.json](../assets/w1/brand/source.json) 记录来源提交、清单摘要及逐文件 SHA256。此次固定来源是 [W1 Brand 草稿 PR #9](https://github.com/Wh1te0ne/W1-Brand/pull/9) 的提交。[品牌副本](../assets/w1/brand/2.0.0-preview.14/) 包含图标、Logo、使用规范与授权文件。各平台的导出路径见[素材说明](../assets/w1/README.md)。品牌图形适用[独立授权](../assets/w1/LICENSE)。

| 使用位置 | 正式资源及规则 |
|---|---|
| 展开侧栏、手机页面标题 | 横向母标与 HARNESS 字标按 W 主体字高对齐；以 48px 高度显示为 184.4 × 48，名称加长时增加宽度 |
| 折叠侧栏、会话首屏、运行状态 | 保留原 Fold 母标的紧凑展示；不修改母标路径 |
| Windows 窗口、托盘、任务栏、启动器 | 全部使用透明前景 ICO，无方形底板；按 Windows 系统明暗选择深色或浅色图形 |
| Web/PWA | favicon 使用明暗透明前景，PWA 的 `any`、`maskable` 和 Apple touch icon 分别使用浅色透明前景、品牌 maskable 图和完整方图 |
| Chrome 扩展、Android 源资源 | 深色完整方图 |

横向 Logo 的浅色主题使用前景 `#252A33`、背景 `#FFFFFF`，深色主题使用前景 `#F5F6F8`、背景 `#17191F`。客户端按应用主题选择正式 SVG，手机页面按系统主题选择。App 图标使用独立配色，浅色主题前景为 `#56595E`，深色主题前景为 `#BFC1C6`。完整 App 源图为 1024 × 1024 方图，圆角由平台裁切。

## 导出与更新

```powershell
node scripts/w1/export-brand.mjs
```

[导出脚本](../scripts/w1/export-brand.mjs) 核对固定资源的 SHA256，再生成 `assets/w1/exports/`、桌面 ICO、客户端 Logo、Web 安装图标和手机及 Chrome 源资源。Windows App ICO 从透明前景 SVG 生成，四角及 W1 镂空保持透明。ICO 包含 16、20、24、32、48、64、128、256 像素八帧，透明母标另有 8192 像素 PNG。PWA 的 PNG 从对应品牌母图等比缩小。修改品牌资源时更新固定来源，再重新导出。

常规品牌更新固定已批准的标签或提交；用户明确要求使用本地稿时，记录工作区与基线提交并校验复制期间的清单稳定性，不编造发布状态。更新固定资源与校验值后运行导出；W1 正在运行时加 `--skip-desktop-icons`，待正常退出后再复制桌面 ICO。已发布版本目录、原始概念图与恢复副本保留。`E:\ProjectDev\W1-Brand\assets\fold\1.1.0` 和本仓库 `releases/w1-brand/1.1.0` 是旧母标素材包，版本名称不代表新的品牌仓库版本；当前产品应从本页固定来源取用。

## 本机接入

`prepareW1SystemIcon` 为窗口、任务栏、托盘和 W1 快捷方式准备同一份透明 ICO。本机安装将图标保存在永久启动器的 `icons/w1-app-<内容摘要>.ico`，打包版使用 Electron 用户数据目录的 `system-icons`。图标跟随 Windows 系统主题，旧文件保留供现有快捷方式使用。本机启动器安装脚本和应用使用同一批桌面资源，快捷方式目标和应用 ID 见[任务栏启动与唤起](开发与上游维护.md#任务栏启动与唤起)。

客户端与桌面主包先暂存，W1 正常退出后在下次启动时应用队列。品牌图形改变时同步更新启动器内嵌图标。分别记录备份、实际加载路径和用户目视确认，Windows Shell 提取图标与重启后的任务栏显示单独验收。

自动检查、实际运行资源与用户目视验收见[工作记录](工作记录.md)。APK、Chrome 扩展和 Windows 安装包按各自的发布流程交付。

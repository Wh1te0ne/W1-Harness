# W1 品牌规范

W1 Harness 使用 [W1 Brand v2.0.0-preview.2](https://github.com/Wh1te0ne/W1-Brand/tree/v2.0.0-preview.2) 的折面平面 App 图标，状态保持 provisional（暂定可用）。横向 Logo、HARNESS 字标和 W1 Fold 母标沿用已批准的原稿；App 图标采用独立产品轮廓与镂空母标。品牌版本与 W1H 产品版本分别管理，品牌预览号不代表恢复独立 Test 开发模式。

## 来源与取用

本机固定品牌提交为 `895ac9e7f1afde19aefa722ac76e037f97c25cf2`，[source.json](../assets/w1/brand/source.json) 记录版本、来源及逐文件 SHA256。[品牌副本](../assets/w1/brand/2.0.0-preview.2/) 包含本产品实际消费的正式资源与授权文件；运行导出入口见[素材说明](../assets/w1/README.md)。品牌图形遵守[独立授权](../assets/w1/LICENSE)，不随代码许可证重新授权。

| 使用位置 | 正式资源及规则 |
|---|---|
| 展开侧栏、手机页面标题 | 横向母标与 HARNESS 字标，最小显示 160 × 48；不再用系统字体重画字标 |
| 折叠侧栏、会话首屏、运行状态 | 保留原 Fold 母标的紧凑展示；不修改母标路径 |
| Windows 窗口、托盘、任务栏、启动器 | 浅底深标的菱形与箭头产品图标，固定浅色版本，不随主题切换 |
| Web/PWA | 明暗主题产品图标；安装图标以浅色方图为源，maskable 图将完整前景及镂空等比缩至 82%，背景保持铺满 |
| Chrome 扩展、Android 源资源 | 深底浅标的产品图标；安装状态以各平台交付记录为准 |

横向 Logo 的浅色主题使用前景 `#252A33`、背景 `#FFFFFF`；深色主题使用前景 `#F5F6F8`、背景 `#17191F`。App 图标浅色背景为 `#F4F5F6`，其余配色遵循固定图标源，不由 Logo token 覆盖。横向 Logo 使用两份正式 SVG，跟随应用实际主题；手机页面跟随系统主题。不要通过 `invert()` 变色。App 源图为完整 1024 × 1024 方图，不预制圆角；平台需要裁切时由平台处理。

## 导出与更新

```powershell
node scripts/w1/export-brand.mjs
```

[导出脚本](../scripts/w1/export-brand.mjs) 核对固定资源的 SHA256，再生成 `assets/w1/exports/` 的固定消费路径、桌面 ICO、客户端资源、Web 安装图标及手机和 Chrome 源资源。正式 1024 PNG 原样复制；平台尺寸由正式图派生。每个 ICO 包含 16、20、24、32、48、64、128、256 像素八帧；透明母标另有 8192 像素 PNG。不得直接修改生成文件或改变产品轮廓与镂空母标的相对位置。分层 SVG 使用原始 512 坐标，导出保留其整体两倍缩放；PWA 只缩放 foreground 图层，校验缺少原始缩放或背景的文件时明确失败。

新增品牌版本时，先在品牌仓库批准并发布，再复制所需文件、更新固定提交与校验值、运行导出。已发布版本目录、原始概念图与恢复副本保留。`E:\ProjectDev\W1-Brand\assets\fold\1.1.0` 和本仓库 `releases/w1-brand/1.1.0` 是旧母标素材包，版本名称不代表新的品牌仓库版本；当前产品应从本页固定来源取用。

## 本机接入

Windows 图标选择仍由 `w1SystemIconPath` 固定为 `w1-app-light.ico`。安装脚本使用已准备的 W1 运行时写入并回读快捷方式，保留应用身份与修改前备份，随后通知 Explorer 刷新。客户端改动只构建相关包，并在正常退出后应用队列；启动器和 Electron 图标缓存也须在退出后更新。

新会话标题仍为「所想，皆有回响」/「Every thought finds an echo」。本次品牌更新不改会话、模型、计价或插件配置。自动检查、实际运行资源与用户目视验收分别记录在[工作记录](工作记录.md)；手机 APK、扩展商店和安装包的发布不能由源码资源同步推定。

# W1 Chrome 自动连接

[English](guide.md) | 中文

## 变更

W1 Chrome 扩展 0.2.0 与 Host 使用协议 2，0.1.0 扩展不能连接更新后的 Host。移除连接码、共享当前标签及仅同站授权。启用的扩展自动发现普通标签，由 W1 选择目标或打开后台页面。安装现在允许发现普通标签，具体操作仍受任务指令及全局/逐页暂停约束。`w1_chrome.disconnect` 只释放当前聊天的标签占用。

## 迁移

0.2.4 将使用的页面收进 W1 分组，增加可信点击回执和有期限的截图恢复。重连仍会使旧标识失效，应先列出并读取再发送输入。桌面任务栏和托盘现统一跟随应用模式：浅色白底深标，深色深底白标。

1. 完全退出 W1，再通过正常快捷方式重新打开，以应用暂存构建。不要使用旧报错窗口里的 Restart 来应用开发更新。
2. 在 `chrome://extensions` 中移除旧解压扩展，启用开发者模式并加载 `releases/w1-chrome/0.2.4/`，安装期间可以关闭 W1。公开扩展 ID 不变；权限包括 `storage`、`alarms`、`tabGroups` 及用于就绪检查的 `127.0.0.1` HTTP 访问。旧发布文件保留。
3. 保持 W1 与 Chrome 运行，面板应自动显示已连接；让 W1 列出 Chrome 标签，无需提供连接码或共享标签。
4. 使用“暂停连接”禁用访问，或展开“网页访问范围”暂停单页。全局暂停会保存。端口自动发现，不再使用旧的手工端口偏好或 W1_CHROME_BRIDGE_PORT。

0.2.4 在打开 WebSocket 前等待 Host 就绪端点。使用操控前需应用配套 Host 构建，安装本身可离线进行。独立 Chromium 已验证离线时错误记录为零、服务启动后自动连接。个人配置中的安装与真实交互仍待验证，见 [Chrome 文档](../../../../packages/w1/chrome-use/README.zh.md)。

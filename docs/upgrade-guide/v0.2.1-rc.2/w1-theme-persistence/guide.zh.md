# W1 外观持久化

[English](guide.md) | 中文

## 变更

W1 将所选主题、明暗配色和自定义 CSS 保存到 ui-theme 实时配置的 appearance 字段。本地 localStorage 仅作迁移来源与最近有效缓存。后台接受后才显示保存成功，读取失败不会用默认值覆盖配置。启动文档包含已保存配色与 CSS。

## 迁移

1. 从 Test 推广前，备份当前本地外观和 profile 补丁，保留已有主题与样式。
2. 启动更新后的应用。正式设置读到后，已有 appearance 优先；字段为空才将有效 w1.appearance.v1 旧值按命名空间版本号迁入。迁移失败保留本地选择并提示。
3. 在 Test 验证旧存储升级、正常退出重开，以及本地缓存缺失后重开；同时核对正式配置文件与实际运行配色。自定义 CSS 须通过相同的 Host 持久化流程验证。
4. 恢复默认会保存明确的默认外观，旧缓存不能使已放弃的主题复活；不要通过清空 Host 字段恢复默认。
5. 回退时停止应用并恢复先前产物；浏览器缓存保留最近已接受的选择。保留正式配置备份供恢复，勿覆盖其他设置。

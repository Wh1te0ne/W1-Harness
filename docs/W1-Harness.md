# W1 Harness

基于 DeepSeek Harness 的独立衍生桌面产品。首版 0.1.0-alpha.1 已实现 W1 身份、免账号进入工作区和上游更新提醒，已打包并通过实际安装、重启、卸载重装与原 DSH 双开验证；开发版已支持项目多目录与主要目录，以及独立“用量”功能；浏览器整合仍待后续实施。

## 当前状态

日常使用已转为本机开发版：桌面和开始菜单的“W1 Harness”通过固定 exe 入口运行本地构建产物，可固定到任务栏；局部更新不生成安装包。启动、规则隔离、更新命令和实际耗时以[开发与上游维护](开发与上游维护.md)为准。

源码位于 `E:\ProjectDev\W1 Harness`。当前开发版为 W1 0.1.0-alpha.2，分支 `codex/w1-upstream-0.2.1-rc.1`，上游基线 `dsh-v0.2.1-rc.1`；仓库保留完整上游历史和升级前定制快照，上游远程名为 `upstream`。自有 origin 尚未配置，提交仅保留在本机。

初始 Alpha.4 的完整构建和隔离启动证据见[原版构建与隔离运行](原版构建与隔离运行.md)；当前 RC.1 的局部构建、Host 核对及待用户验收范围见[RC.1 同步记录](上游同步-0.2.1-rc.1.md)。上游仍为预发布版本。

## 目录归属

`apps/`、`packages/`、`native/`、`vendor/`、`scripts/` 等沿用上游结构。`scripts/w1/` 保存 W1 本地辅助脚本；`.work/` 保存被忽略的工具、缓存、隔离数据及验证证据。根 README 保留上游说明并指向本页。

现有插件源码仍在 `E:\ProjectDev\DeepSeek Harness` 独立维护；2026-10-16 已按用户授权，将生产 DSH 的数据和插件副本导入 W1 本机开发版。范围、恢复及验证见[开发与上游维护](开发与上游维护.md#dsh-数据迁移)。W1 源码目录不会自动成为已经打开的 Codex 聊天的工作目录；开始新开发任务时确认路径并阅读 AGENTS.md。

# W1 Harness

基于 DeepSeek Harness 的独立衍生桌面产品。首版 0.1.0-alpha.1 已实现 W1 身份、免账号进入工作区和上游更新提醒，已打包并通过实际安装、重启、卸载重装与原 DSH 双开验证；开发版已支持项目多目录与主要目录，以及独立“用量”功能；浏览器整合仍待后续实施。

日常使用已转为本机开发版：桌面“W1 Harness 开发版”直接运行本地构建产物，局部更新不生成安装包。启动、规则隔离、更新命令和实际耗时以[开发与上游维护](开发与上游维护.md)为准。

源码位于 `E:\ProjectDev\W1 Harness`。独立 Git 仓库保留完整上游历史，首版开发分支为 `codex/w1-first-release`，基线标签为 `dsh-v0.2.1-alpha.4`，上游远程名为 `upstream`。自有远程 origin 尚未配置；本轮定制、品牌资源及说明保留为本地工作区改动，尚未创建下游提交或推送。

原版完整构建和实际 Electron 隔离启动已通过；详细状态与边界以[原版构建与隔离运行](原版构建与隔离运行.md)为准。标签为 Alpha，构建通过不表示正式稳定版本。

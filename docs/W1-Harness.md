# W1 Harness

公开产品说明见[仓库 README](../README.zh.md)，产品版本与 DSH 基线、日用/测试/安装环境见[版本与发布](版本与发布.md)，打包和 GitHub 发布见[发布操作](发布操作.md)。W1H 0.1.0-alpha.4 已发布为独立预览发行；本机日用实例保持现有开发入口，生效情况单独记录。

基于 DeepSeek Harness 的独立衍生桌面产品。首版 0.1.0-alpha.1 已实现 W1 身份、免账号进入工作区和上游更新提醒，已打包并通过实际安装、重启、卸载重装与原 DSH 双开验证；开发版已支持项目多目录与主要目录，以及独立“用量”功能；内置浏览器操控首版已实现，构建与验收状态见工作记录。

## 目录归属

`apps/`、`packages/`、`native/`、`vendor/`、`scripts/` 等沿用上游结构。`scripts/w1/` 保存 W1 本地辅助脚本；`.work/` 保存被忽略的工具、缓存、隔离数据及验证证据。根 README 保留上游说明并指向本页。

现有插件源码仍在 `E:\ProjectDev\DeepSeek Harness` 独立维护；2026-10-16 已按用户授权，将生产 DSH 的数据和插件副本导入 W1 本机开发版。范围、恢复及验证见[开发与上游维护](开发与上游维护.md#dsh-数据迁移)。W1 源码目录不会自动成为已经打开的 Codex 聊天的工作目录；开始新开发任务时确认路径并阅读 AGENTS.md。

## 设置与外观

「设置 → 远程连接」集中管理中继、扫码配对、电脑确认和已绑定手机；原侧栏及独立窗口入口取消。通知用铃铛、外观用调色盘、远程连接用手机图标。侧栏插件、用量和自动化任务共用固定 18px 图标栏与文字起点。

「设置 → 外观」包含明暗/跟随系统、字体与字号、工作步骤展示/折叠时机、性能与用量显示；既有偏好保留。另有 W1 默认及 Absolutely、Codex、Catppuccin、Everforest、GitHub、Linear、Notion、One、Raycast、Rosé Pine、Vercel 共 11 套双模式参考配色，可分别编辑浅色和深色的强调色、背景、前景，导入/导出 JSON，自定义 CSS。有效修改立即生效并自动保存，无需预览确认；色值未输入完整时保持上一次有效配色。主题仅在 W1 本地生效；恢复默认不重置会话数据。

主配色由本机 Codex 26.1013.4894.0 的主题 JS 资源静态读取，记录在 ui-theme 的 w1-presets.ts，W1 自行适配 token；没有执行 Codex 包内代码，也不声称复刻全部布局或代码高亮。整包 REA 分析未完成，其未打包原生附件存在清单校验差异；参考颜色只来自单独提取的主题资源，不依赖该附件。原始参考位于被忽略的 .work/codex-theme-reference/。

## 日常使用与开发更新

W1 默认关闭构建文件热加载。packages/ 局部构建暂存，下一次正常退出并重开时才发布；重复唤起已有窗口不会应用更新。根界面临时卸载时显示恢复提示，注册恢复后自动返回；初次启动缺失根注册仍报错。开发步骤与限制见[开发与上游维护](开发与上游维护.md)。

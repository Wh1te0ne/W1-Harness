# W1 Harness 三阶段改造

核验日期：2026-10-19。仅更新 `E:\ProjectDev\W1 Harness` 的本机开发版，不打包，不修改原版 DSH。用户已授权按“完成前复核 → MCP 声明按需加载 → 缓存诊断”顺序实施。

## 术语与边界

| 名称 | 本次含义 |
|---|---|
| Plugin | Cordis 加载单元。本次新增三个 W1 Plugin；Plugin 本身不是模型调用函数。 |
| MCP | 接入外部服务能力的协议。一个 MCP Server 可以声明多个具名操作。 |
| Skill | 具名说明与资源，通过现有 `skill` 工具读取；本次不修改 Skill 加载。 |
| Tool | 模型可以按具体名称与参数调用的操作，例如 `update_goal`、`w1_tool_catalog`、`mcp__...`。 |
| ToolDefinition | 运行时实现、执行函数、权限与来源信息。 |
| ToolSchema | 发送给模型的名称、说明和参数声明。按需加载调整的是这部分可见性，不是执行授权。 |

## 接入与影响模块

| 阶段 | 接入点 | 结果 |
|---|---|---|
| 完成前复核 | `goal/tool-goal` 新增 `goal/before-model-complete`；`w1/goal-review` 实施策略；`client/ui-goal` 显示状态 | 完成提议先经现有权限与版本校验，再执行独立、无工具的复核；通过后仍由 Goal 服务比较并更新。 |
| MCP 声明按需加载 | `core/tools` 保留非 wire 的 origin；`mcp/mcp-client` 填写原始身份；`w1/mcp-tool-catalog` 过滤已按权限组装的 Native 声明 | 先搜索目录，再 load 精确名称；下一步才发送具体声明。已选声明按会话持久化，权限与声明变化重新核验。 |
| 缓存诊断 | `w1/cache-diagnostics` 监听主循环请求；`llm/llm-deepseek` 提供序列化后惰性摘要；`client/ui-chat` 展示 | C1 表示模型请求结构；C2 表示实际 DeepSeek 请求结构。追加消息不算前缀重写；未知计数、服务端 TTL 和缓存键不推定。 |

现有 agent-loop 没有重写。完成前复核不会自动创建 Goal；仅在模型提议完成现有目标时调用。MCP 服务照常启动，PTC 描述和 MCP 服务指令段保留现状。

## 三个开关

W1 Web 组成在 `packages/bundle/web-app/cordis.patch.yml` 明确启用三个独立插件；各插件独立配置的 `enabled` 默认均为 false。停用某一行或将 enabled 设为 false 可单独撤回该行为。配置字段、效果和限制分别见 [goal-review](../packages/w1/goal-review/README.zh.md)、[mcp-tool-catalog](../packages/w1/mcp-tool-catalog/README.zh.md)、[cache-diagnostics](../packages/w1/cache-diagnostics/README.zh.md)。

复核沿用当前主模型路由和推理设置，不自动改用其他供应商；每份不变证据最多一次辅助请求。需求未完成时向主模型返回缺口；超时、无效输出、证据超限或中断保留未完成状态，解除自动续跑，不冒充目标受阻。暂停、清除、修改目标或新的人类输入使在途复核失效。

复核证据与请求位置使用有界增量投影，恢复时由事件重建，不新增同步历史扫描。复核失败时再次核对目标身份和版本，旧目标的迟到结果不会解除新目标的自动续跑。

## 改善的证据口径

200 项回归验证机制与兼容行为，不是改造前后真实任务的 A/B。当前证据如下：

| 项目 | 已证实的变化 | 尚未证实 |
|---|---|---|
| 完成前复核 | 缺证据或拒绝结论能够拦截完成提议；去重、超时、取消及目标替换不误写完成 | 真实任务成功率、误拒率和复核模型判断质量；复核会增加辅助调用 |
| MCP 按需声明 | 20 个无关 MCP 声明的合成场景中，初始声明 UTF-8 字节少于全量的 1/5；加载后下一步披露并能执行桥接操作 | 真实模型选择能力、端到端耗时、总输入 Token 和账单下降比例 |
| 缓存诊断 | 可以区分追加与既有前缀变化，保留未知计数并显示 C1/C2 观测来源 | 服务端缓存键、TTL 和实际成本改善；诊断本身不调整请求前缀 |

## 持久化与回退

新增必需事件为 `w1/goal-review-attempt`、`w1/goal-review-request`、`w1/goal-review-result`、`w1/mcp-disclosure`、`w1/cache-diagnostic`。读取目录与类型变更记录一起更新，不使用 ignorable 绕过恢复约束。尝试先于辅助付费请求持久化；重启不自动重新购买历史复核。主模型声明的权威历史仍是既有 request/header 与 toolHistory。

关闭行为开关不撤回会话已写入的事件，因此必须保留新版读取器。旧版 W1 会拒绝包含未知必需事件的日志；不假定直接降级安全。原 DSH 不读取 W1 的新记录，也不参与本次更新。

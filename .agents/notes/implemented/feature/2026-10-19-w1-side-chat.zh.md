# Agent Note: W1 临时侧边聊天

Status: implemented

[English](2026-10-19-w1-side-chat.md) | 中文

## Problem

用户需要在主任务进行时提问，而不增加主会话历史、队列或草稿。已有右侧栏提供合适的标签生命周期和开始页。

## Decision

W1 侧聊插件注册一个开始页入口和普通聊天标签。打开时固定主会话上下文并始终携带这份快照，模型路线与请求取消控制独立。侧聊向主聊天的 `model.selector` Factory 传入独立状态和回调，复用搜索、分组及模型声明的推理档位，切换时不修改主会话模型。有历史的标签关闭前需要确认。精确请求和响应写入未注册到持久化的内存 Session 日志，标签保持流断开后清除。侧聊不创建或恢复 Agent，也不提供工具。

## Alternatives considered

派生普通 Agent 会引入可执行工具及持久项目历史。复用主输入框会耦合草稿、停止和排队输入。独立聊天本身不能证明费用降低或背景充分，因此不隐式选择小模型或缩短上下文。

## Consequences

旁支问题不会打断主任务执行或静默改变其上下文，但仍消耗模型 Token。关闭标签和连接断开后丢弃侧聊历史；持久化、工具与自动合并不在本功能范围。所属 [README](../../../../packages/w1/side-chat/README.zh.md) 定义行为与验证。合成的前后端测试覆盖快照隔离、多轮消息、取消、失败、生命周期与输入法；真实供应商和原生显示缩放验收单独记录。

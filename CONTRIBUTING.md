# Contributing to W1 Harness

English | [中文](CONTRIBUTING.zh.md)

Report W1H bugs and feature requests in [this repository](https://github.com/Wh1te0ne/W1-Harness/issues), including W1H version, integrated DSH baseline, platform, reproduction steps, and expected behavior. For sensitive reports, follow [SECURITY.md](SECURITY.md).

Keep changes focused. Read [AGENTS.md](AGENTS.md), the owning package README, and [development guidance](docs/开发与上游维护.md). Preserve W1 identity, user data, and upstream compatibility. Run relevant tests and explain what remains unverified; automated checks do not replace native acceptance.

Use a feature branch and submit a pull request with the problem, resulting behavior, compatibility impact, and validation. Discuss broad changes first. Review and release timing depend on maintainer availability.

Never submit real keys, sessions, browser profiles, pairing information, or deployment credentials. Docker examples use placeholders. Retain upstream copyright and third-party notices.

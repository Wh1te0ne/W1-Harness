# W1 品牌资源导航

取用图片请进入[按用途分类的素材包](../../releases/w1-brand/README.md)：头像、透明标志、应用图标、预览和矢量源文件。完整说明见[品牌规范](../../docs/W1品牌规范.md)。

| 位置 | 用途 | 维护方式 |
|---|---|---|
| mark.svg | 唯一几何源文件 | 编辑图形或统一位置的入口 |
| exports/ | 应用、构建与脚本使用的尺寸和配色导出 | 保持现有路径，由导出脚本生成 |
| preview.png | 各尺寸和配色预览 | 随导出重建 |
| reference-concepts.png | 原始设计选择依据 | 历史参考，不是待替换的旧应用图标 |

产品目录中的 ICO、PNG 和内联 SVG 是实际消费者，不能因名称相似就删除。候选、备份、测试证据与本目录分开；清理范围及更新状态见项目工作记录。

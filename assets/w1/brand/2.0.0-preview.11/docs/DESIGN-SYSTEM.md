# W1 品牌规范 2.0 预览

## 用途与当前状态

W1 Fold 是家族母标。产品全称仍为 W1 Home、W1 Harness 等。**产品 Logo、专属字标和 App 图标是不同资产**，各自具有设计确认状态；修改 App 图标不意味着修改 Logo。

| 场景 | 当前构成 | 状态 |
| --- | --- | --- |
| 界面顶部、登录页、产品介绍 | W1 在左、专属字标在右的横排 Logo | Home、Harness、Status 已确认。TV、Calendar、Video 暂定 |
| 应用启动器、系统 App 入口 | 产品独立轮廓＋镂空 W1，每款采用独立的平面前景色 | 七款彩色图标暂定 |
| 母品牌展示 | 独立 W1 Fold | 原始几何不变 |

Music 本次只有 App 图标，未在本仓库设计或确认产品 Logo。Calendar 的横排 Logo 和字标见文末，尚待用户确认。旧“W1 上、产品字标下”的双行 App 图标由新暂定方案替换；旧稿可从 `v1.1.0` 找到。

## 母标与产品 Logo

母标唯一来源是 `src/brand/w1-fold.svg`。保留五段图形、切缝、方向、转折和纵横比；不得打字替代、AI 重画或手工描摹。App 图标中只整体等比缩放和平移母标。

Home 与 Harness 继续使用已有专属矢量字标；字标不是完整字库，也不是正文字体。图形中的切缝保持透明。界面标题、说明和按钮仍使用产品自身的 UI 字体。

Logo 主题保持不变：

| 主题 | 图形 / 字标 | 固定表面 |
| --- | --- | --- |
| light | `#252A33` | `#FFFFFF` |
| dark | `#F5F6F8` | `#17191F` |

`dist/tokens/brand.css` 描述母标 / Logo 的主题，不用于覆盖 App 图标的配色。产品整个 UI 不需要因此改色。

## 横排 Logo 统一标准（所有产品）

所有产品使用同一规则，由生成器按 `brand.json` 的 `layout.interface` 计算，`npm run check` 逐个产品校验：

- **字高对齐：** 字标上沿对齐 W 主体上沿（`y≈96.2`），下沿对齐 W 主体下沿（`y≈288.3`），字高约 `192.1`。“1”的尖高出字标，这是预期效果。
- **长度随名字变化：** 字高固定，字标按原比例缩放，名字越长 Logo 越长。不压缩字高或字宽来凑统一长度。
- W1 布局框宽 `280`，左侧 `x=94`，顶部 `y=70`；字标左侧 `x=466`，与 W1 布局框间距 `92`。
- 画布高 `360`，右侧留白 `94`，宽度随字标计算：Home `1197`、Harness `1383`。
- 母标复用布局框为 `[47,95,395,308]`，并非重绘或裁切母标路径。
- 字标矢量的墨迹必须顶到 viewBox 的上下边，否则无法对齐。

不拉伸横排 SVG，不压缩间距，不用普通字体重新输入 HOME / HARNESS。按高度规定尺寸：Logo 文件高度不低于 48px，优先 60px 以上（此时 W 主体和字高约 26 / 32px）；同一界面中的不同产品用相同高度，不用相同宽度。外部内容与品牌实际轮廓之间至少留当前 W1 显示宽度的 1/8，内置画布留白可计入。

## App 图标

“折面平面”（`fold-flat`）靠产品轮廓和前景色区分。Home 为屋顶和屋身，Music 为音符，Calendar 为页眉、吊环和页面，Harness 为菱形和箭头，TV 为横向电视和脚架，Status 为竖向手机和两道上报回波，Video 为带折角的播放三角。单个图标用一种实色，玻璃等动态材质交给平台。半透叠片旧稿见 `v2.0.0-preview.1`。

每个产品的权威源稿为 `src/products/<id>/app-icon-light.svg` 与 `app-icon-dark.svg`。生成器按登记的源稿缩放、导出并分离图层。

- 源稿画布 `512 × 512`；完整 SVG / PNG 交付画布 `1024 × 1024`。
- W1 使用未改动的五段路径，只整体缩放和平移，保持水平，并从图形中镂空为真正透明。
- W1 的位置和宽度由容器决定，按产品登记在 `products/<id>.json` 的 `appIcon.mark`。源稿内宽度分别为 Home `212`、Music `192`、Calendar `208`、Harness `184`、TV `204`、Status `190`、Video `194`。
- 浅色底为 `#F4F5F6`，深色底为 `#17191F`。深浅色共用同一几何，前景色按下表取用。
- 视觉重量以图形实际覆盖率约 31%–36% 为目标（Home 34%、Music 31%、Calendar 36%、Harness 32%、Status 32.78%、Video 32.82%）。调整或新增产品时一并复核。
- 圆角和切缝：折角半径 `5`，切缝宽度约 `15`–`16`。
- `background` / `foreground` 图层可重新组合为完整图标。前景保留透明度，完整 PNG 是不透明 RGB。
- 正式文件为完整方形，圆角交给平台处理。展示页的圆角、名称和对齐参考线不进入 App 图标。

## 各平台的背景与主题要求

所有产品都同时有浅色和深色模式，因此 Logo 和图标一律成对交付，并按实际主题取用。

所有场景共用同一图形来源 `app-icon-foreground`，是否加底按平台决定，不要用一张图通吃：

| 场景 | 背景 | 取用文件 | 主题跟随 | 原因 |
| --- | --- | --- | --- | --- |
| 网页内 Logo | **透明** | `interface-logo.svg` / `.png` | 页面实际主题 | 页面表面就是底色 |
| 网页内固定品牌底 | 自带底色 | `interface-logo-on-surface` | 页面实际主题 | 只用于需要品牌固定底的位置 |
| 网页标签页图标（favicon） | **透明** | `app-icon-foreground` | 系统主题 | 浏览器不加底，标签栏颜色也不由页面决定 |
| Windows | **透明** | `app-icon-foreground.png` / `.svg` | 系统主题 | 系统不替应用裁圆角，方形底会直接显示成方块 |
| Android 自适应图标 | 前景透明，背景层不透明 | `app-icon-android-foreground` + `app-icon-background` | 系统主题 | 系统按形状裁切，前景已缩进安全区 |
| Android TV 横幅 | 不透明，满铺 | `android-tv-banner.png`（320 × 180） | 按应用资源选择 | 提供横向启动入口，保留完整横排 Logo |
| PWA `any` 图标 | **透明** | `app-icon-foreground` | 只能放一个文件时待确认 | 不会被裁切 |
| PWA `maskable` 图标 | 不透明，满铺 | `app-icon-maskable` | 只能放一个文件时待确认 | 系统按形状裁切，图形已缩进安全区 |
| iOS / iPadOS App | 不透明，满铺 | `app-icon.png` / `AppIcon.appiconset` | Any / Dark | 系统裁圆角，并要求不带透明通道 |
| 网页 `apple-touch-icon` | 不透明，满铺 | `app-icon.png` | 只能放一个文件时待确认 | 透明处在 iOS 主屏幕上通常显示为黑色 |
| macOS 等其他平台 | 接入时确认 | 待确认 | 待确认 | 尚未有产品接入 |

**透明资产必须按主题取用：** 透明图形没有底色托着，要靠图形自身和背后的表面形成对比。`light/` 的深色图形用于浅色表面，`dark/` 的浅色图形用于深色表面，反过来会几乎看不见。

**网页内 Logo 跟随页面主题：** 产品有主题开关时由开关决定，不能只看系统设置，否则用户手动选了浅色，Logo 仍可能显示深色版。标签栏不属于页面，所以 favicon 跟随系统主题。

**只能放一个文件的场景：** 单个 `.ico`、`apple-touch-icon` 和 PWA manifest 图标选深色还是浅色，待确认。

**裁切安全区：** 被系统裁切的图标，图形必须留在安全区内。全家族使用同一缩放比例，以保持视觉重量一致，比例登记在 `brand.json` 的 `layout.appIcon.safeZones`，`npm run check` 逐产品校验。

下表的数值是距中心最远的图形点 ÷ 图标宽度（1024px 实测）：

| 产品 | 原始前景 | `app-icon-maskable`（缩放 0.78，上限 0.40） | `app-icon-android-foreground`（缩放 0.60，上限 0.3055） |
| --- | --- | --- | --- |
| Home | 0.501 | 0.391 | 0.300 |
| Calendar | 0.485 | 0.378 | 0.291 |
| TV | 0.477 | 0.372 | 0.286 |
| Status | 0.470 | 0.367 | 0.283 |
| Video | 0.463 | 0.362 | 0.278 |
| Harness | 0.455 | 0.355 | 0.273 |
| Music | 0.451 | 0.352 | 0.271 |

Android 的上限来自 108dp 画布中直径 66dp 的安全区。比例由最大的 Home 决定，新产品超出时先调整图形，确实需要时再改全家族的比例。不要把未缩放的 `app-icon.png` 或 `app-icon-foreground` 用在这两处，也不要在消费项目里手工缩放或改图。

裁切效果预览：`dist/previews/app-icons-safe-zones.png`。四行依次是 `maskable` 圆角、`maskable` 最小圆形、Android 72dp 圆形、Android 66dp 安全圆形，左右为浅色和深色。

## 小尺寸与变更边界

检查 32 / 64 / 128px 的不同轮廓、明暗和切缝。32px 下不保证 W1 的细节均可读；不能仅凭大图或统一色就认定已解决找图问题。真实设备的查找速度仍需体验。

不要将暂定 App 图标替换到横排 Logo 或字标文件；不要在单个产品中长期自行改母标、配色或对齐，也不要把高光、落影等材质效果画进源稿。改变图形需回到源稿，记录用户选择并生成新版本。选稿与保护基线见 `docs/PROVENANCE.md`。

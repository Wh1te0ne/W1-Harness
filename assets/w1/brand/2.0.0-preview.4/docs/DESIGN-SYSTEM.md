# W1 品牌规范 2.0 预览

## 用途与当前状态

W1 Fold 是家族母标。产品全称仍为 W1 Home、W1 Harness 等。**产品 Logo、专属字标和 App 图标是不同资产**，各自具有设计确认状态；修改 App 图标不意味着修改 Logo。

| 场景 | 当前构成 | 状态 |
| --- | --- | --- |
| 界面顶部、登录页、产品介绍 | W1 在左、专属字标在右的横排 Logo | Home、Harness 已按字高对齐标准重排，2026-11-05 确认 |
| 应用启动器、系统 App 入口 | 产品独立轮廓＋镂空 W1，平面单色 | 2026-11-05 暂定，provisional |
| 母品牌展示 | 独立 W1 Fold | 原始几何不变 |

Music、Calendar 本次只有 App 图标，未在本仓库设计或确认产品 Logo。旧“W1 上、产品字标下”的双行 App 图标由新暂定方案替换；旧稿可从 `v1.1.0` 找到。

## 母标与产品 Logo

母标唯一来源是 `src/brand/w1-fold.svg`。保留五段图形、切缝、方向、转折和纵横比；不得打字替代、AI 重画或手工描摹。App 图标中只整体等比缩放和平移母标。

Home 与 Harness 继续使用已有专属矢量字标；字标不是完整字库，也不是正文字体。图形中的切缝保持透明。界面标题、说明和按钮仍使用产品自身的 UI 字体。

Logo 主题保持不变：

| 主题 | 图形 / 字标 | 固定表面 |
| --- | --- | --- |
| light | `#252A33` | `#FFFFFF` |
| dark | `#F5F6F8` | `#17191F` |

`dist/tokens/brand.css` 描述母标 / Logo 的主题，不用于覆盖 App 图标的配色。产品整个 UI 不需要因此改色。

## 横排 Logo 统一标准（所有产品）

所有产品使用同一规则，由生成器按 `brand.json` 的 `layout.interface` 计算，`npm run check` 逐个产品校验：

- **字高对齐：** 字标上沿对齐 W 主体上沿（`y≈96.2`），下沿对齐 W 主体下沿（`y≈288.3`），字高约 `192.1`。“1”的尖高出字标，这是预期效果。
- **长度随名字变化：** 字高固定，字标按原比例缩放，名字越长 Logo 越长。不压缩字高或字宽来凑统一长度。
- W1 布局框宽 `280`，左侧 `x=94`，顶部 `y=70`；字标左侧 `x=466`，与 W1 布局框间距 `92`。
- 画布高 `360`，右侧留白 `94`，宽度随字标计算：Home `1197`、Harness `1383`。
- 母标复用布局框为 `[47,95,395,308]`，并非重绘或裁切母标路径。
- 字标矢量的墨迹必须顶到 viewBox 的上下边，否则无法对齐。

不拉伸横排 SVG，不压缩间距，不用普通字体重新输入 HOME / HARNESS。按高度规定尺寸：Logo 文件高度不低于 48px，优先 60px 以上（此时 W 主体和字高约 26 / 32px）；同一界面中的不同产品用相同高度，不用相同宽度。外部内容与品牌实际轮廓之间至少留当前 W1 显示宽度的 1/8，内置画布留白可计入。

## 暂定 App 图标

“折面平面”（`fold-flat`）靠产品轮廓区分：Home 为屋顶加屋身，Music 为音符，Calendar 为页眉、吊环加页面，Harness 为菱形把任务交给箭头，箭头同时呼应命令提示符。图形平面单色，不画渐变、高光、描边或落影；玻璃等动态材质交给平台，不写进源稿。上一版半透叠片见 `v2.0.0-preview.1`。

每个产品的权威源稿为 `src/products/<id>/app-icon-light.svg` 与 `app-icon-dark.svg`。这八份 SVG 固定本轮选稿，生成器只缩放、导出并分离已有图层，不根据产品名字临时画图。

- 源稿画布 `512 × 512`；完整 SVG / PNG 交付画布 `1024 × 1024`。
- W1 使用未改动的五段路径，只整体缩放和平移，保持水平，并从图形中镂空为真正透明。
- W1 的位置和宽度由容器决定，按产品登记在 `products/<id>.json` 的 `appIcon.mark`，不再全家族相同：Home `212`、Music `192`、Calendar `208`、Harness `184`（源稿坐标）。这取代了上一版“统一 W1 位置和大小”的规则。
- 配色：浅色底 `#F4F5F6`、图形 `#252A33`；深色底 `#17191F`、图形 `#F5F6F8`。深浅色共用同一几何。
- 视觉重量：图形实际覆盖率控制在约 31%–36%（Home 34、Music 31、Calendar 36、Harness 32）。调整或新增产品时一并复核。
- 圆角和切缝：折角半径 `5`，切缝宽度约 `15`–`16`。
- `background` / `foreground` 图层可重新组合为完整图标。前景保留透明度，完整 PNG 是不透明 RGB。
- 正式文件为完整方形，圆角交给平台处理。展示页的圆角、名称和对齐参考线不进入 App 图标。

当前交付不包含动态玻璃、Icon Composer 工程或其他平台特定外观。暂定选择允许取用，不等同于最终视觉定稿或真机验收。

## 小尺寸与变更边界

检查 32 / 64 / 128px 的不同轮廓、明暗和切缝。32px 下不保证 W1 的细节均可读；不能仅凭大图或统一色就认定已解决找图问题。真实设备的查找速度仍需体验。

不要将暂定 App 图标替换到横排 Logo 或字标文件；不要在单个产品中长期自行改母标、配色或对齐，也不要把高光、落影等材质效果画进源稿。改变图形需回到源稿，记录用户选择并生成新版本。选稿与保护基线见 `docs/PROVENANCE.md`。

## TV 补充

TV 沿用本页统一横排标准，画布 867 × 360，不另设字高、间距或母标位置。电视轮廓 App 图标的 W1 宽 204；源稿新增浅深色两份。TV 的 Logo 和图标均是用户要求实施的 provisional，等待实际视觉反馈，详情见 [TV 记录](TV.md)。

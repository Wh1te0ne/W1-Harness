# W1 回复建议

[English](README.md) | 中文

主聊天完成一轮回答后，W1 提供一条可选的下一句用户回复草稿。输入框为空且空闲时显示；Tab 填入，Esc 忽略，用户另行确认发送。已有命令菜单、带修饰键的 Tab 和中文输入法组合过程优先处理。

## 模型选择

当前主模型从既有子代理设置中已启用、明确允许的模型路由里选择。W1 提供模型配置中的名称与描述，不虚构价格或延迟测量。选择结果按会话、主模型及允许路由列表缓存；这些条件改变后，在下次生成时重新选择。未启用选择或选择失败时继承当前主模型。生成前再次核对允许列表，拒绝已被移除的选中路由。

建议通过正常 LLM 服务和用量记账链路发起无工具的辅助请求，不创建子代理，也不自动发送用户消息。辅助请求和结果记录在主对话上下文之外；仅提取最近的用户及助手文本，排除工具、推理与附件。新轮次、会话释放及插件卸载会取消待完成工作。生成失败时保留普通输入框，并记录不含模型输入或凭据的诊断。

## 配置

Web 组成明确提供全部限制：最近 6 条消息、12,000 个上下文字符、完整输入 65,536 字节、输出 768 Token、建议 240 字符，模型元数据或模型操作各有 30 秒期限。提供方须遵守取消信号。忽略状态仅保存在当前挂载的输入框中。

## 保存建议与历史会话

每个会话从持久化日志恢复自己的最新建议。重新打开聊天或重启应用时，直接读取已保存的文字，不调用模型。打开旧会话时，仅在最后一轮正常完成的回答既无建议记录、也无尝试记录时补生成一次。应用启动不会扫描全部历史聊天并批量生成。

模型工作前先将尝试记录写盘，成功后再将建议写盘。空结果、失败或中断的尝试不会因重新打开而反复执行。有新一轮正常完成的回答时，允许一次新尝试并替换旧建议。已有建议与请求记录也视为已经尝试过。历史中断轮次，以及没有已完成助手文本的聊天，不参与补生成。

## 模型体验

没有路由决策时，选择模型增加一次主模型调用。后续每个已完成轮次通常增加一次建议模型调用。辅助调用使用独立提示词和受限文本上下文，不复用主聊天完整前缀，也不改变主聊天 KV 缓存历史。请求选中模型已声明的最低推理强度。即使用户忽略建议，这些调用仍产生用量。

## 已知限制与延期工作

建议质量依赖模型；建议只是可编辑草稿，不代表用户意愿。模型目录没有经过验证的速度排名。不支持的模型或空白、截断、超长、类似命令的输出不显示建议。选中模型失败时，不在同一轮换模型重试。不推断图片和附件里的内容。

会话兼容及应用回退要求见[首次持久化记录](../../../docs/persistence-changes/2026-10-17-w1-reply-suggestions.zh.md)与[持久化补生成记录](../../../docs/persistence-changes/2026-10-17-w1-reply-backfill.zh.md)。不识别新事件名的旧版会拒绝相关会话；回退应用时应保留新版读取器，或恢复升级前的私有会话备份。

# W1 内置用量

[English](README.md) | 中文

## 概述

W1 的应用功能模块，侧栏“用量”与“插件”“自动化任务”同级。页面提供总览、用量明细、模型价格和设置，复用原有 Token、费用估算、预算、会话统计和历史账本。官方 DeepSeek 余额与钱包授权继续关闭；模型 API Key 仍由 W1 凭据库管理。

侧栏同时显示今日估算 API 费用和总 Token；点击进入用量，悬浮或聚焦显示最多八个渠道/模型的费用与用量。会话费用明细只在顶部会话标题栏保留入口。

## 价格与消费记录

所有记账金额与显示价格统一为人民币。手填价绑定精确的渠道与模型，官方同步不能覆盖。OpenRouter 官方模型接口只为已配置的 OpenRouter 渠道按精确模型 ID 提供价目，不为其他渠道匹配价格。已知 DeepSeek、火山、VX 渠道绑定自己的来源；其他渠道需明确选择。VX Default、High（GPT/Claude高档货）、Enterprise 分组精确隔离。上一版导入且未改动的 VX 记录转为跟随对应来源；之后手动编辑的记录保持锁定。来源每六小时刷新，失败退避重试、保留上次有效模型价格，并显示时间、状态、模型问题和重试按钮。空响应或未知规则不能清除旧价。没有公开价格 API 时解析官方页面；暂不支持的模型保持手填或未定价。价格未知时保留 Token 与调用次数，并提示费用不完整。

模型价格使用唯一编号和生效时间留存版本。修改、删除与恢复只影响之后的调用。删除需要确认，记录移至独立的已删除页面；浏览该页不会恢复记录。恢复生成新版本，同模型存在有效价格时拒绝覆盖。同模型同价格再次添加，也生成不同版本。手填价格采用人民币每百万输入、缓存命中输入、输出 Token；可选峰谷计费按请求完成的北京时间，分别配置工作日、时段和节假日。普通输入、输出、缓存读取、缓存写入、一小时写入分别展示。一小时写入是总写入量的子集；上下文阈值和实际发送的思考强度参数进入逐调用费用与统计。缓存时长不明时标记估算，动态倍率所需参数缺失时标记未定价。OpenAI 十二小时写入保持独立，缺少时长用量时标记待核对。

折叠的汇率设置支持手填美元兑人民币汇率，或获取 Frankfurter 的 ECB 每日参考值。点击自动模式即保存并获取，应用运行时每日检查；失败退避重试并保留有效汇率、日期及提示。价格保存后返回最新状态，无需重启；版本检查阻止迟到快照覆盖新价。美元价目按调用完成时已保存的汇率换算，汇率变更不会重算历史人民币消费。保留已经有依据的历史修正。消费凭据迁移先备份账本，其余旧人民币金额固定不变，明细不足的按渠道/模型/日期显示历史汇总，不再被旧的严格核对规则阻挡。新调用生成唯一编号，在同一次原子账本替换中保存完整用量、实际计费参数、人民币单价、汇率和最终金额，并更新合计。主调用、回复建议选模/生成、旁路对话、压缩和原生搜索统一入账，同量独立调用不合并。中断保留已报告用量，未报告用量明确未定价。最终用量在 finish 事件前落盘；写入失败保留待写凭据重试并提示。逐次凭据遵循历史明细保留天数，归档日合计仍保留。详见[迁移与回退说明](../../../docs/upgrade-guide/v0.2.1-rc.2/w1-cny-pricing/guide.zh.md)。

经明确授权，可通过 `scripts/reprice-history.mjs` 执行一次性历史纠错。在目标应用停止时预览并应用冻结方案：使用精确 Provider/模型价格，保留已有消费凭据与用量总数，同时修正会话、日期和渠道合计。逐次日志提供时间和上下文；日志不完整时保留账本各类 Token 总数，按日志中的档位比例分摊。无日志按平均上下文和当天峰谷时长加权；缺写入时长按普通写入，缺 effort 按 1 倍，完全缺用量的按同渠道同型号平均值估算金额而不改写 Token。所有假设写入私有对账报告并保留修正前备份。重复应用不会重复计费；账本变化后须重新预览。模型价格与逐模型峰谷设置统一在“用量”维护，移除重复的 DeepSeek 峰谷设置入口。

已记录的估算金额作为历史消费保留，侧栏和用量明细不再持续显示待核对提示。归档模型价格会立即移除该型号的当前同步问题，保留带日期的价目与全部消费；晚到的同步结果不会恢复已删除价格或对应提示。实际未配置价格及当前来源获取失败仍保留明确状态。

<a id="model-experience"></a>

## 模型体验

此功能显示本地通知或已记录用量，不发起模型请求，也不独立提供模型上下文。

#### KV 缓存影响

此功能不增加模型提示或工具声明，也不改变模型请求前缀。

<a id="known-limitations-and-deferred-work"></a>

## 已知限制与后续工作

- 估算不等于供应商账单。缓存按时存储费、Batch/Flex 折扣及非 Token 附加费不自动推断；不同计费模式应配置独立渠道并填写实际单价。旧明细不足时保留有标识的历史汇总，不虚构逐次价格。

<a id="dev-note"></a>
### 开发备注

应用的 packages/bundle/web-app/cordis.patch.yml 默认加载本模块；它不再声明 dsh.bundle，也不作为用户可选插件安装。包名 dsh-usage-manager、usageManager 服务名、usageManagerUsage 投影名和账本路径保持不变，；人民币迁移独立执行并保留备份。代码仍通过 Cordis 模块注册，与 W1 其他内置功能采用相同机制。

数据位于 W1 的 DSH_HOME/storages/cost-meter-custom，旧私有插件副本仅保留用于回退。启动脚本 scripts/w1/migrate-usage.mjs 在 W1 停止时备份 profile 与账本，移除外部 dsh-usage-manager 和未启用的旧 dsh-cost-meter 安装记录，再由应用内置组成接管；不删除旧副本或修改账本。

运行 node scripts/build.mjs 只重建浏览器模块；Host JavaScript 和 lib/vendor 中的原有打包依赖随源码维护，tsdown.config.ts 避免通用打包器覆盖这些源文件。开发环境刷新链接使用 scripts/w1/Start-W1.ps1 -RefreshProject，日常启动可直接使用桌面快捷方式。无需生成安装包。

沿用 Cost Meter 的 MIT 许可，归属与第三方许可见 LICENSE、UPSTREAM.md、THIRD_PARTY.md。W1 差异包括官方钱包关闭策略、独立主页面与默认应用装配；上游更新时保留这些行为。用量页使用与会话费用相同的可观察数据源，注册随模块卸载释放，不新增第二套计费监听。

# @deepseek-ai/dsh-w1-browser-use

[English](README.md) | 中文

## 概述

Agent 可在 W1 内置浏览器中打开、读取、导航、点击、填写、滚动、按常用键、后退和截图。每个标签页归属一个聊天。用户可在工具栏暂停操控，恢复需要用户操作。Desktop Host 提供 [Chrome 传输](../chrome-use/README.zh.md)时，同一个提供方还注册 `w1_chrome`，操控自动发现的外部标签；两个工具均不操控 Windows 桌面。

## 使用本包

桌面 Host 使用私有传输挂载本 Cordis 插件。它不是可单独安装的 bundle 或纯 Web 插件。组合提供 30 秒操作期限、12,000 字符页面正文和 100 条元素描述；执行端还限制完整编码结果大小。请求创建浏览器标签前，先在 W1 中打开对应聊天。

可选 `chromeRequest` 回调增加独立的 `w1_chrome` 工具与作用域内流程，不占用第二个浏览器提供方。Chrome 支持相同的页面动作，另有 `connect` 和 `disconnect`。自动连接及标签发现独立于内置浏览器，[扩展接入与操控](../chrome-use/README.zh.md#connection-and-control)由 Chrome 传输维护。模型传入 Session ID 无法改变任何一个工具的调用方归属。

描述任务即可，例如：“检查这个页面的姓名字段是否正常。”无需点名浏览器工具：指引要求 Agent 在需要渲染、交互或视觉检查时主动使用，同时遵守你的限制。“暂停操控/允许操控”作用于当前标签页。取消轮次会停止后续输入，已经送达的操作不会回滚。取消或超时后，重试前先读取页面当前状态。

<a id="understand-the-implementation"></a>

调研先使用搜索与正文读取；只有确需渲染、交互或已授权登录时，才依照[工具选择规则](../tool-selection/README.zh.md)回退到浏览器。自动操作复用当前会话的后台标签页并尊重已关闭的侧栏；重复网络故障或策略拒绝不构成继续开页的理由。

## 理解实现

<details>
<summary>执行与生命周期</summary>

插件注册一个提供方和 w1_browser 工具。归属由实际 Agent 的 Session 提供，模型不能指定另一个聊天。私有子进程消息到达桌面执行端，每次操作前校验已批准 guest 租约及聊天归属。Renderer IPC 要求来自产品主文档。固定脚本在 guest 隔离世界中运行；模型参数不能提供 JavaScript、协议方法或 Electron 对象。点击和按键直接发送给 guest webContents，不注入操作系统输入。

执行端拒绝同一标签页的重叠操作。暂停、关闭、断线与取消会停止待完成工作。取消后，标签页持续占用，直到底层工作结束。再次读取、填写、点击或文档替换使旧元素引用失效；定位过程中导航会拒绝输入。失败后的输入结果需要重新观察才能确认。文本与截图经过既有工具结果及附件流程。

</details>

<a id="model-experience"></a>
## 模型体验

### 浏览器工具

#### 模型看到什么

工具说明包含支持的动作、新鲜元素引用、页面内容不可信及核验要求。通用工具卡显示动作与结果。观察包含标签及非敏感表单值，不返回密码和文件字段的值。截图要求支持图片的模型及附件存储。 `w1:browser-workflow` 提示段要求 Agent 列出并复用目标标签页、读取新鲜引用、顺序执行有依赖的操作，并再次读取验证结果。视觉改动在支持图片时需检查截图。遇到暂停、拒绝、不支持的操作或结果不明时，应说明情况，不能绕过或盲目重试。工具被限制、覆盖或卸载时不提供该段落。[产品级选择规则](../tool-selection/README.zh.md) 负责工具之间与浏览器环境之间的选择。

#### Token 影响

工具定义、操作指引和观察占用上下文。观察按工具结果持久化；截图使用附件引用。

#### KV Cache 影响

不变的工具定义与操作指引提供稳定请求前缀。新观察追加到聊天历史；工具可见性变化会改变其指引与工具前缀。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 内置工具读取主文档的普通 DOM。不支持跨域框架、Shadow DOM 元素发现、上传、下载、密码输入或任意 JavaScript；外部标签使用独立的 Chrome 工具。内置网站存储仍限于进程生命周期。创建内置标签要求桌面客户端已接纳该聊天；视图不可用时会超时，不将操作转给其他聊天。Canvas 元素定位留待后续。点击和按键使用 guest 调试器；调试器已被占用时明确拒绝，不断开其他客户端。

验证使用合成页面、真实 Cordis/Agent 调用链、无密钥的随附 headless profile 会话回放及模拟 Electron guest。这些测试不代表原生验收或实际模型效果。本机构建及验收状态见 [W1 工作记录](../../../docs/工作记录.md)。
